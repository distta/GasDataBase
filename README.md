# GasDataBase

面向气体探测器研究的 Garfield++ / Magboltz 气体文件数据库。你可以按配方查找 `.gas` 文件，在浏览器中查看和比较气体参数曲线，再下载原始文件、曲线数据或图像。

**[打开在线气体数据库 →](https://distta.github.io/GasDataBase/)**

在线使用无需安装软件、下载仓库或启动服务器。网站提供已有气体表的检索和展示，不执行在线 Magboltz 计算。

## 快速上手

以查看 Ar/CO₂ 混合气体为例：

1. 在「组分与比例」中保留两行，分别选择 `Ar` 和 `CO2`；通过「添加组分」或行末的「×」调整行数。
2. 输入目标比例，例如 70% 和 30%；温度、压强可以留空，也可以填写希望查找的条件。
3. 点击结果中的气体配方，预览曲线。通过上方标签切换漂移速度、扩散、倍增、附着等参数。
4. 选择磁场 B 和夹角 θ，查看对应工况。点击「详情」可检查文件温压、计算网格和来源记录。
5. 点击结果行中的「下载」获取原始 `.gas` 文件；需要曲线数据或图片时，使用绘图区的「导出」。

## 查找合适的气体文件

筛选条件修改后，结果会自动更新。

- **组分行数决定组分数量**：一行查找纯气，两行查找二元混合气，三行查找三元混合气。某行选择「不限」，表示该位置可以是任意组分。
- **比例以百分比填写**：填写 `70` 表示 70%，留空表示不指定目标比例。
- **温度使用 °C，压强使用 atm**：留空表示不指定目标温压。
- **比例和温压用于相近排序**：当前页面会优先展示比例更接近的文件，再考虑温压接近程度，也可能列出其他比例或温压的文件。下载前请核对结果中的实际数值。
- **结果数量区分配方和文件**：「种」表示不同配方数，「份」表示文件数；同一配方可能有多份不同条件的文件。

没有结果时，先检查组分名称和行数，或点击「重置」重新设置条件。

## 比较和查看曲线

勾选结果行左侧的复选框，将文件加入比较，最多同时比较 **8 份**。列表上方的「加入比较」会按当前排序加入前几份未选文件，直到达到上限。可以在「已选比较」中移除文件或清空选择。

点击某个配方可单独预览，再点击「返回已选文件比较」恢复叠加曲线。

| 操作 | 使用方式 |
| --- | --- |
| 切换物理量 | 选择漂移速度、扩散、倍增、附着或「更多」，再选择具体分量 / 参数 |
| 切换工况 | 使用 B 和 θ 下拉框，查看文件已有的磁场和夹角截面 |
| 切换横轴 | 在 E、E/p、E/N 之间选择，单位显示在坐标轴上 |
| 查看具体数值 | 将鼠标移到采样点，或展开「曲线数据与参数说明」 |
| 放大局部 | 在图中拖拽框选；双击恢复，也可手动填写坐标轴显示范围 |
| 调整显示 | 开关横轴 / 纵轴对数坐标，以及采样点显示 |

不同文件可能提供不同的参数或工况。页面会禁用未提供的参数，并提示当前比较中缺失的项目；某条曲线未出现时，请查看图下方提示。多种温压同时比较时，各文件条件会显示在图例中。

## 导出结果

绘图区右上方的「导出」提供三种格式：

| 格式 | 导出内容 | 常见用途 |
| --- | --- | --- |
| CSV | 当前曲线在所选工况、显示范围及有效坐标内的采样点，附文件标识、温压和单位等信息 | 后续分析、制表或自行绘图 |
| 原始 `.gas` | 当前图中各条曲线对应的完整气体文件，包含全部工况 | 用于 Garfield++ 气体表加载及后续模拟 |
| SVG | 当前图像 | 插入文档或使用矢量绘图软件编辑 |

**CSV 会随当前截面和显示范围变化；原始 `.gas` 文件包含完整数据。** 比较多份文件时，原始文件会逐份下载；如果浏览器阻止连续下载，可允许该网站下载多个文件，或使用各结果行的「下载」。

## 比较自己的本地文件

点击「＋ 本地文件」，或将文件拖入页面，即可将自己的气体表加入比较。可以同时选择多个文件，也可以与数据库中的文件叠加查看，总数仍受 8 份限制。

本地文件仅在浏览器中读取，**不会上传，也不会自动收录到数据库**。当前选择和导入文件不会在刷新后自动恢复，建议先导出需要的结果。

## 理解数据与单位

- 曲线上的采样点来自文件中的原始计算记录，连线仅辅助阅读，页面不生成额外插值点，也不作外推。
- 参数按文件记录的温度和压强还原。切换 E/p 或 E/N 横轴不会把数据转换成其他温压下的计算结果。
- 漂移速度以 **cm/μs** 显示；纵向、横向扩散以 **μm/√cm** 显示；α、η 以 **cm⁻¹** 显示。倍增系数 α 不等同于气体增益。
- B = 0 时，界面统一显示 θ = 90°；这是显示约定，原始记录中的夹角仍保留在文件详情和数据导出中。
- 文件详情可查看计算网格、来源与生成信息、原始记录及完整性信息。未记录的来源或版本不能视为已知。

完整的参数含义、单位换算和来源依据见[气体参数展示约定](Doc/气体参数展示约定.md)。

## 常见问题

**为什么输入指定比例或温压后，还会看到其他条件？**

这些输入目前用于排列相近结果，并非严格过滤。请以列表和文件详情中的实际配方、温压为准。

**为什么选中文件后没有曲线？**

文件可能没有提供当前参数或 B / θ 工况。查看图下方提示，尝试其他参数或工况；也可以点击「恢复自动范围」，排除手动坐标范围的影响。对数坐标无法显示零值或负值。

**为什么直接打开下载的 `index.html` 无法加载目录？**

请优先使用[在线网站](https://distta.github.io/GasDataBase/)。需要本地运行时，在仓库根目录执行以下命令，再访问终端给出的地址（默认是 `http://127.0.0.1:8000`）：

```bash
python3 tools/catalog.py --serve
```

## 维护与贡献

添加气体文件、补充元数据和更新索引，请参阅[简易数据库维护说明](Doc/简易数据库维护说明.md)；部署网站请参阅[快速开始](QUICK_START.md)。

正式气体文件位于 [`GasDataBase/`](GasDataBase/)，按气体体系分类；网页代码位于 `index.html` 和 `assets/`，收录配置、索引与来源记录位于 `catalog/`。

公开仓库包含网页、正式数据库和发布所需代码。来源记录中的 `runs/` 路径指向本地计算工作区，相关计算任务和完整日志不随网站发布。
