# 发布库维护

正式气体文件放在 `GasDataBase/<类型>/<气体体系>/`，目前展示 363 份当前气体表，另有 42 份独立来源归档。网页只展示现有数据，不执行在线计算。

## 目录与文件

| 路径 | 用途 |
| --- | --- |
| `GasDataBase/` | 正式气体表 |
| `catalog/config.json` | 收录目录与参考计算网格 |
| `catalog/metadata.json` | 文件状态与来源摘要 |
| `catalog/provenance.json` | 完整来源、原始文件哈希和生成设置 |
| `catalog/gas_aliases.json` | 气体名称别名 |
| `catalog/gases.json`、`catalog/report.json` | 当前网页索引和构建校验报告 |
| `index.html`、`assets/` | 网页与静态资源 |
| `tools/`、`tests/` | 构建、解析和校验代码 |

`original/` 旧库存、一次性迁移报告和过时整理方案已清理。来源记录中的历史路径仅作为来源标识保留，旧文件副本不再随当前工作区提供。已收录气体表的原始字节和来源哈希保持不变；无法确认的生成设置仍记为未知。

`simulation/`、`runs/` 及计算报告用于本地计算，不随公开仓库发布。`_site/` 是可重新生成的部署目录。

## 添加与发布文件

1. 在计算工作区完成气体表与来源校验，再将正式文件放入对应分类目录。
2. 更新 `catalog/config.json`、`catalog/metadata.json` 和 `catalog/provenance.json`。元数据键使用正式文件的相对路径。
3. 执行以下命令生成并校验网页索引，打包网站：

```bash
python3 tools/catalog.py
python3 tools/catalog.py --check
python3 tools/build_site.py
```

推送 main 后，GitHub Actions 自动校验并发布 Pages。首次部署设置见 [快速开始](../QUICK_START.md)。本地预览可执行 `python3 tools/catalog.py --serve`。

参考网格是新计算模板，不是已有文件收录的强制门槛。同设置不同网格须在计算工作区核验、合并后再发布，网页构建过程不修改气体表。不同来源或未知设置的表不能直接合并。版本由 Git 保存，前端展示当前数据。用户补充的同配方、同温压但生成设置未知的表保留在对应体系的 `archive/` 中，元数据标记为 `archived`，来源与哈希仍记入 `catalog/provenance.json`；这些表不与当前表直接拼接，也不在前端重复展示。

## 分类与命名

目录、文件名、页面名称及下载名称统一把稀有气体放在其他组分前，同类组分按名称排序。例如：

- `GasDataBase/Ar+X/Ar_CO2/`：Ar 二元体系。
- `GasDataBase/Ar+X+Y/Ar_CH4_O2/`：Ar 三元体系。
- `GasDataBase/Ne+X/Ne_CF4/`：Ne 二元体系。
- `GasDataBase/Pure/He/`：纯 He。
- `GasDataBase/X+Y+Z/C2H2F4_iC4H10_SF6/`：不含稀有气体的三元体系。

`Pure` 表示单组分，`X`、`Y` 等为其他组分占位符；多个稀有气体时使用排序最前的稀有气体作为类型前缀。

当前库已筛除温度不为整数摄氏度或压强不为 0.01 atm 整数倍的历史条目；这属于收录选择，不代表其他工况在物理上无效。文件条件必须以表内记录为准，不能通过改名或四舍五入改变实际工况。

网页使用方法见 [README](../README.md)，参数和单位约定见 [气体参数展示约定](气体参数展示约定.md)。
