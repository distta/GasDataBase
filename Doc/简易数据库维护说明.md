# 发布库维护

正式气体文件放在 `GasDataBase/<气体体系>/`，配置收录目录在 `catalog/config.json`。来源和状态在 `catalog/metadata.json`，完整来源信息集中在 `catalog/provenance.json`。历史库存、计算程序与运行日志留在计算工作区。

新文件在计算工作区完成入库后，将正式文件及更新后的配置、来源记录同步到本仓库。然后执行：

```bash
python3 tools/build_site.py
```

推送main后GitHub Actions自动生成索引并发布Pages。首次需将Settings → Pages → Source设置为GitHub Actions。访客无需运行本地服务器。

参考网格是新计算模板，不是历史文件入库的强制门槛。同设置不同网格在计算工作区合并后再发布，网页构建过程不修改气体表。版本由Git保存，前端仅展示当前数据。
