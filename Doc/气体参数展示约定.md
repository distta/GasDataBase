# 气体参数展示约定

适用于 `index.html` 的气体目录与绘图页面。所有参数在文件记录的温度、压强下还原，不对其他温压外推。

| 分类 | 参数 | 展示单位 | 文件数值的还原方法 |
| --- | --- | --- | --- |
| 漂移速度 | 沿 E、沿 B⊥、沿 E×B | cm/μs | 分别读取 raw.ve、raw.vb、raw.vexb |
| 扩散 | 纵向 Dₗ、横向 Dₜ | μm/√cm | raw.dl 或 raw.dt / √p × 10⁴ |
| 倍增 | α、无 Penning α₀ | cm⁻¹ | p × exp(raw.alpha 或 raw.alpha0) |
| 倍增 | 有效系数 α−η | cm⁻¹ | 还原后的 α 减去 η |
| 附着 | η | cm⁻¹ | p × exp(raw.eta) |
| 倍增 / 附着 | α/p、η/p | cm⁻¹ Torr⁻¹ | exp(raw.alpha 或 raw.eta) |
| 倍增 / 附着 | α/N、η/N | cm² | 还原后的系数除以 N（cm⁻³） |
| 碰撞速率 | 各激发、电离通道及其总和 | ns⁻¹ | 直接读取 raw.excitationRates、raw.ionisationRates；总量为对应通道求和 |

p 使用文件中的 Torr 压力；N 使用文件温压按理想气体关系计算。扩散量是漂移距离平方根归一化的空间扩散量，不是 cm²/s 的扩散常数。倍率系数并非气体增益；本界面不根据它自动计算增益。

“更多”保留迁移率、Lorentz 角、扩散张量、离子解离与碰撞速率/通道。尚未核实单位的扩展物理字段仍标明“文件原值”或现有换算，不能据此假定单位。原始数值、误差和未解释扩展值从绘图选择列表移除，在文件详情的逐条记录中保留。

参数可用性同时检查 GASOK 和实际有限数值。未提供的参数禁用；多文件比较时，仅提供该参数的文件参与绘制，并提示缺失项。图上连线只连接采样点，不生成额外插值记录。

此次统一仅改变目录页面的漂移参数选择及读取方式，通用解析器中的 cm/ns 字段继续保留以兼容旧工作台。

## 激发与电离速率单位核实

2026-09-10 对照 Garfield++ 官方源码：`MediumMagboltz::GenerateGasTable` 以 `1.e3 * ftot / ntotal` 将 ps⁻¹ 转为 ns⁻¹，再乘通道碰撞次数，写入 `m_excRates`、`m_ionRates`。日志也明确标注 `Rate [ns-1]`。`MediumGas` 读写气体文件时直接读写这些速率，不作额外缩放。因此当前解析器无需数值换算，绘图单位为 ns⁻¹。它表示电子群体平均的每电子通道碰撞频率，不是能级能量，也不是单位体积总反应次数。

源码依据：
- [MediumMagboltz.cc：气体表生成与速率单位](https://gitlab.cern.ch/garfield/garfieldpp/-/blob/master/Source/MediumMagboltz.cc#L2964)
- [MediumGas.cc：气体文件速率写出](https://gitlab.cern.ch/garfield/garfieldpp/-/blob/master/Source/MediumGas.cc#L1989)

比例一致性校验：Identifier 百分比按显示末位半单位容纳舍入差异，并保留警告；不改写原始 Mixture 数值。此规则仅处理文件内部精度差异，不是检索的 ±1 个百分点容差。

洛伦兹角：文件为弧度（Garfield++ RunMagboltz 使用 atan2，写出不缩放）。前端统一以 raw.lorentz × 180 / π 显示为 °，包括绘图、悬停与当前曲线数据；原始文件和原始记录保持弧度。
